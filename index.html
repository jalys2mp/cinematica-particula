Cinemática da Partícula Simulação Interactiva
ℹ Como utilizar esta simulação
1Escolhe um cenário no painel esquerdo (ex: Lançamento Oblíquo) ou define os parâmetros manualmente com os sliders.
2Prime ▶ ANIMAR MOVIMENTO para iniciar. Usa ⏸ PAUSA para parar e ↺ REINICIAR para repetir.
3Ativa ou desativa os vetores (posição, velocidade, aceleração) com os botões coloridos abaixo do gráfico.
4Clica em 📈 Gráficas para ver as gráficas temporais x(t), y(t), vₓ(t), vᵧ(t), aₓ(t), aᵧ(t). Clica numa gráfica para a ampliar. Volta à simulação com ◀ Simulação.
5Após animar, abre a aba Questões no painel direito — as perguntas são geradas com os valores reais da tua simulação.
⚠Queda Livre e Lançamento Oblíquo: define sempre y₀ > 0 (slider "Posição inicial Y") para que o objeto tenha espaço para cair. Com y₀ = 0 a simulação termina imediatamente.
⚠Travagem: é necessário aₓ < 0 para que o objeto desacelere. Se aₓ = 0, o objeto move-se indefinidamente sem parar.

📡 Interpretação em Tempo Real
Define v₀ₓ, v₀ᵧ, aₓ e aᵧ e prime ▶ ANIMAR.
▸Define v₀ₓ≠0, v₀ᵧ=0, aₓ≠0, aᵧ=0 → MRUA em X. A velocidade aumenta linearmente e x(t) é uma parábola.
▸Define v₀ₓ=0, aᵧ=−9,8 → Queda livre em Y. O vetor aponta sempre para baixo.
▸Combina v₀ₓ≠0 e v₀ᵧ≠0 com aᵧ=−9,8 → Lançamento oblíquo com trajetória parabólica.
▸ (roxo) liga o ponto inicial ao atual. É diferente de (azul) que parte sempre da origem.
▸Ativa vₓ e vᵧ separadamente para ver como cada componente evolui no tempo.
▸No lançamento oblíquo, no ponto mais alto, vᵧ = 0. Confirma nos cartões de métricas.
🔒 Questões bloqueadas Executa a simulação com o botão ▶ ANIMAR para desbloquear as questões deste cenário.
